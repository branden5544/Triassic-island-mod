Triassic Island 0.1.0 (alpha test build)
=========================================
Dinosaurs (61 species, DNA cloning), an Electrical Age-style power grid,
Python computers, security, park fences, lights, phones.

INSTALL
  Minecraft 1.20.1 with Forge 47.1+ or NeoForge 1.20.1 (47.1.x).
  Put triassicisland-0.1.0.jar in the mods folder. Nothing else is required.
  The jar is ~46 MB because Jython (Python 2.7 for the computers) is bundled.

OPTIONAL MODS
  Simple Voice Chat - enables phone calls.
  Create 6.0.x      - adds Kinetic Generators (rotation -> electricity, 1 SU = 1 W).

QUICK START
  Everything is in the "Triassic Island" creative tab, including ready-to-hatch
  eggs for every species. Most blocks need power: a Combustion Generator with
  coal next to them (or connected by cable) is the quickest way to test.
  Right-click any power block with a Multimeter to see volts/amps/watts.

KNOWN LIMITS
  - Art is placeholder (generated textures, code-built dinosaur models).
  - Very large dinosaurs path poorly on rough terrain.
  - Camera views only show areas within the viewer's render distance.
  - Computers are sandboxed, but servers can disable them in
    serverconfig/triassicisland-server.toml.

REPORTING BUGS
  Please include what you did, what happened, and the crash report
  (crash-reports/) or logs/latest.log.
